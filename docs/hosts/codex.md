# Installing deliberation in the OpenAI Codex CLI

[Codex](https://developers.openai.com/codex) installs reusable bundles as native
**plugins**. The deliberation plugin lives in `plugins/deliberation/` in this repo
and is discoverable through a repo-scoped marketplace, all generated by
`scripts/sync-hosts.js` from the canonical sources (`docs/tool-guide.md`, `prompts/*.md`).

## Install

```
codex plugin marketplace add antonbabenko/deliberation
```

Then open the plugin directory with `/plugins` inside Codex and install
**deliberation**. Codex reads the repo-scoped marketplace at
`.agents/plugins/marketplace.json`, whose entry points at the plugin subdirectory
`./plugins/deliberation` (a root `source.path` of `.` is rejected -
openai/codex#17066 - so the plugin is shipped in a subdirectory).

## What the plugin ships

Plugin root: `plugins/deliberation/`

- `.codex-plugin/plugin.json` - manifest. `interface` carries the required
  `displayName`, `developerName`, `category`, and `capabilities` fields; `version`
  is kept in sync with `version.json` by the release pipeline.
- `.mcp.json` - registers the MCP server (`npx -y @antonbabenko/deliberation-mcp`,
  stdio).
- `skills/deliberation/SKILL.md` - "when to delegate" (from `docs/tool-guide.md`).
- `skills/<expert>/SKILL.md` - one skill per expert (`architect`, `plan-reviewer`,
  `scope-analyst`, `code-reviewer`, `security-analyst`, `researcher`, `debugger`, `writing-editor`),
  each carrying that expert's persona so Codex gets the same guidance natively.
- `skills/reload-mcp/SKILL.md` - steps to pick up a new version (clear the npx cache, stop the dashboard, restart the MCP server).

Once installed you get the deliberation MCP tools (`ask-all`, `consensus`,
`ask-gpt` / `ask-gemini` / `ask-grok` / `ask-openrouter`, and the eight experts).

## Provider credentials

The MCP server reads credentials from the host environment. Set only the providers
you use:

| Provider | How it authenticates |
|----------|----------------------|
| GPT (Codex) | Codex CLI auth (`codex login`, e.g. ChatGPT - `codex login --device-auth` on a remote machine; or `CODEX_ACCESS_TOKEN`; else `CODEX_API_KEY`) |
| Gemini | `GEMINI_API_KEY` (Google AI Studio key; `GOOGLE_API_KEY` also works). Opt-in fallback: the Antigravity CLI (`agy`) - see the terms note below |
| Grok (xAI) | `XAI_API_KEY` |
| OpenRouter | `OPENROUTER_API_KEY` (advisory-only; declare models in `~/.config/deliberation/config.json`) |

Gemini note: with no key, Gemini falls back to the Antigravity CLI (`agy`). Read the
[Antigravity terms](https://antigravity.google/terms) first. Section 6 lists "Using third
party software, tools, or services to access the Service (e.g. using OpenClaw with
Antigravity OAuth)" as a breach that "may be grounds for suspension or termination of your
Antigravity and/or Gemini CLI accounts". deliberation drives `agy` as third-party software.

Missing keys just disable that one provider.

## Updating

The plugin starts the server with `npx -y @antonbabenko/deliberation-mcp`. The npm package
does not include this repository's `scripts/` folder. After an update:

```bash
# stop the dashboard; prints "no running dashboard" if none runs
npx -y @antonbabenko/deliberation-mcp dashboard --stop
# drop the cached old build of this package (macOS, Linux)
find ~/.npm/_npx -type d -path '*/@antonbabenko/deliberation-mcp' -prune -exec rm -rf {} +
```

On Windows, `dashboard --stop` is not supported: close the dashboard process first, then
delete the `@antonbabenko\deliberation-mcp` folders under `%LocalAppData%\npm-cache\_npx`.

Then start a new Codex session so it starts the new server. The `reload-mcp` skill gives the
same steps. In a clone of this repository, `bash scripts/commands/reload-mcp.sh` clears the cached package, restarts the dashboard
and audits the running deliberation processes.

If you use the dashboard, start it again on the new version with
`npx -y @antonbabenko/deliberation-mcp dashboard`.
