# Installing deliberation in Cursor

[Cursor](https://cursor.com) connects to the deliberation MCP server and reads a
project **rule** that tells the agent when to delegate. Both pieces are below.

## 1. Add the MCP server

Use the one-click button from the [README](../../README.md#install) ("Install in
Cursor").

The one-click deeplink (`cursor://anysphere.cursor-deeplink/mcp/install?...`)
cannot carry secrets - set provider keys in your environment (see below).

### Other ways to install

Add the server by hand to `~/.cursor/mcp.json` (global) or `.cursor/mcp.json`
(project):

```json
{
  "mcpServers": {
    "deliberation": { "command": "npx", "args": ["-y", "@antonbabenko/deliberation-mcp"] }
  }
}
```

## 2. Add the rule

Copy the generated rule into your project so Cursor knows when to reach for the
experts:

```
.cursor/rules/deliberation.mdc
```

It is generated by `scripts/sync-hosts.js` from `examples/cursor.md`. The
frontmatter (`description`, `alwaysApply`) controls when Cursor loads it; the body
routes plan/architecture/security reviews and second opinions to the right tool.
The full surface (same as every host) is the fan-out / single-provider tools
(`ask-all`, `consensus`, `ask-gpt` / `ask-gemini` / `ask-grok` / `ask-openrouter`)
and the eight experts (`architect`, `plan-reviewer`, `scope-analyst`,
`code-reviewer`, `security-analyst`, `researcher`, `debugger`, `writing-editor`).

## Provider credentials

The MCP server reads credentials from the host environment. Set only the providers
you use:

| Provider | How it authenticates |
|----------|----------------------|
| GPT (Codex) | Codex CLI auth (`codex login`, e.g. ChatGPT - `codex login --device-auth` on a remote machine; or `CODEX_ACCESS_TOKEN`; else `CODEX_API_KEY`) |
| Gemini | `GEMINI_API_KEY` (Google AI Studio key; `GOOGLE_API_KEY` also works). Opt-in fallback: the Antigravity CLI (`agy`) - see the terms note below |
| Grok (xAI) | `XAI_API_KEY` |
| OpenRouter | `OPENROUTER_API_KEY` (advisory-only; declare models in `~/.config/deliberation/config.json`) |

Gemini note: with no key, Gemini falls back to the Antigravity CLI (`agy`). Read the
[Antigravity terms](https://antigravity.google/terms) first. Section 6 lists "Using third
party software, tools, or services to access the Service (e.g. using OpenClaw with
Antigravity OAuth)" as a breach that "may be grounds for suspension or termination of your
Antigravity and/or Gemini CLI accounts". deliberation drives `agy` as third-party software.

Missing keys just disable that one provider.

## Updating

Cursor starts the server with `npx -y @antonbabenko/deliberation-mcp`. The npm package does
not include this repository's `scripts/` folder. After an update:

```bash
# stop the dashboard; prints "no running dashboard" if none runs
npx -y @antonbabenko/deliberation-mcp dashboard --stop
# drop the cached old build of this package (macOS, Linux)
find ~/.npm/_npx -type d -path '*/@antonbabenko/deliberation-mcp' -prune -exec rm -rf {} +
```

On Windows, `dashboard --stop` is not supported: close the dashboard process first, then
delete the `@antonbabenko\deliberation-mcp` folders under `%LocalAppData%\npm-cache\_npx`.

Then restart the deliberation server in Cursor's MCP settings, or reload the window. In a
clone of this repository, `bash scripts/commands/reload-mcp.sh` clears the cached package, restarts the dashboard
and audits the running deliberation processes.

If you use the dashboard, start it again on the new version with
`npx -y @antonbabenko/deliberation-mcp dashboard`.
