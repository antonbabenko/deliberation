# Installing Deliberation in Antigravity CLI & Gemini Code Assist

[Antigravity CLI](https://antigravity.google) (`agy`) and Gemini Code Assist support
agent skills and project-level MCP server configurations. The Deliberation artifacts
are generated by `scripts/sync-hosts.js` into `.agents/` and `.gemini/` from the
canonical sources (`docs/tool-guide.md`, `prompts/*.md`).

## Install

Copy `.agents/skills/` and `.agents/mcp.json` from this repository into your project's `.agents/`
directory:

```bash
git clone --depth 1 https://github.com/antonbabenko/deliberation /tmp/deliberation
mkdir -p .agents && cp -R /tmp/deliberation/.agents/skills /tmp/deliberation/.agents/mcp.json .agents/
```

### Other ways to install

- Gemini Code Assist: also copy `.gemini/skills/` into your project's `.gemini/`.
- Working inside a clone of this repository: Antigravity and Gemini Code Assist discover the
  skills and the MCP configuration in the project root, with no copy step.

## What is generated

- `.agents/mcp.json` - MCP configuration registering `@antonbabenko/deliberation-mcp`.
- `.agents/skills/` - Cross-agent standard skills:
  - `deliberation/SKILL.md`: "When and how to delegate" (from `docs/tool-guide.md`).
  - `<expert>/SKILL.md`: The 8 expert subagents (`architect`, `plan-reviewer`,
    `scope-analyst`, `code-reviewer`, `security-analyst`, `researcher`, `debugger`, `writing-editor`).
  - `reload-mcp/SKILL.md`: Steps to pick up a new version (clear the npx cache, stop the dashboard, restart the MCP server).
- `.gemini/skills/` - Workspace-level skill mirror for native Gemini Code Assist discovery.

## Usage

Once installed or placed in the project root, Antigravity and Gemini Code Assist automatically
discover the workspace skills and project-level MCP tools:
- **Workspace Skills**: Specialized expert personas (`@architect`, `@code-reviewer`, `@debugger`, `@plan-reviewer`, `@security-analyst`, `@scope-analyst`, `@researcher`, `@writing-editor`) and delegation guidance (`@deliberation`).
- **MCP Tools**: Multi-model consensus and peer-review tools (`consensus`, `consensus-step`, `ask-all`, `ask-gpt`, `ask-gemini`, `ask-grok`, `ask-openrouter`) called directly by the agent or host.

## Provider credentials

Provider credentials come from the host environment:

| Provider | How it authenticates |
|----------|----------------------|
| Gemini | `GEMINI_API_KEY` (Google AI Studio key). Opt-in fallback: the Antigravity CLI (`agy`) - see the terms note below |
| GPT (Codex) | Codex CLI auth (`codex login` / `codex login --device-auth`) or `CODEX_API_KEY` / `CODEX_ACCESS_TOKEN` |
| Grok (xAI) | `XAI_API_KEY` |
| OpenRouter | `OPENROUTER_API_KEY` (models configured in `~/.config/deliberation/config.json`) |

Gemini note: with no key, Gemini falls back to the Antigravity CLI (`agy`). Read the
[Antigravity terms](https://antigravity.google/terms) first. Section 6 lists "Using third
party software, tools, or services to access the Service (e.g. using OpenClaw with
Antigravity OAuth)" as a breach that "may be grounds for suspension or termination of your
Antigravity and/or Gemini CLI accounts". Deliberation drives `agy` as third-party software.

## Updating

Antigravity starts the server with `npx -y @antonbabenko/deliberation-mcp`. The npm package
does not include this repository's `scripts/` folder. After an update:

```bash
# stop the dashboard; prints "no running dashboard" if none runs
npx -y @antonbabenko/deliberation-mcp dashboard --stop
# drop the cached old build of this package (macOS, Linux)
find ~/.npm/_npx -type d -path '*/@antonbabenko/deliberation-mcp' -prune -exec rm -rf {} +
```

On Windows, `dashboard --stop` is not supported: close the dashboard process first, then
delete the `@antonbabenko\deliberation-mcp` folders under `%LocalAppData%\npm-cache\_npx`.

Then restart the Deliberation MCP server in Antigravity, or restart Antigravity. The
`reload-mcp` skill gives the same steps. In a clone of this repository,
`bash scripts/commands/reload-mcp.sh` clears the cached package, restarts the dashboard
and audits the running Deliberation processes.

If you use the dashboard, start it again on the new version with
`npx -y @antonbabenko/deliberation-mcp dashboard`.
